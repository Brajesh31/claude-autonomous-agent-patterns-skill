# Autonomous Agent Patterns

Design autonomous agents using reusable planning, execution, tool-use, and coordination patterns.

## Features

- Domain-focused workflows and implementation guidance.
- Practical patterns and examples.
- Best practices and validation considerations.

## Installation

Copy the skill into your agent skills directory:

```bash
mkdir -p .claude/skills/autonomous-agent-patterns
cp SKILL.md .claude/skills/autonomous-agent-patterns/SKILL.md
```

## Usage

Ask your AI coding assistant to use **Autonomous Agent Patterns** for a related task and follow the instructions in `SKILL.md`.
